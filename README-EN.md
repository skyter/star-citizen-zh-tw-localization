# Star Citizen 4.10.2 — Taiwan Traditional Chinese (English item/place names)

Unofficial, non-commercial Traditional Chinese localization derived from the 42Kit / Star Citizen Chinese localization community's **4.10.2(PU)_CNE_V2** semi-localization. It preserves English item, ship and place names from the upstream variant.

The translation is largely an OpenCC `s2twp` conversion, with a small number of manually rewritten user-facing hints. **It has not been comprehensively proofread or tested in-game.**

Download [`global.ini`](global.ini), place it at `StarCitizen/LIVE/data/Localization/chinese_(traditional)/global.ini`, then set `g_language = chinese_(traditional)` in `StarCitizen/LIVE/user.cfg`. Back up existing configuration first. The language pack does not modify the executable, archive or anti-cheat.
